Create API Token

ProxOrchestrator needs a Proxmox API token to manage VMs. Create one with limited privileges in two minutes.

{# Commands to run on the Proxmox host #}
Run in the Proxmox shell

In the Proxmox web UI at https://{{ proxmox_host }}:{{ api_port }} open your node → Shell and paste these lines. They create a dedicated user with only the privileges ProxOrchestrator needs (not root) and a token for it.

pveum user add proxorchestrator@pve --comment ProxOrchestrator pveum acl modify / --users proxorchestrator@pve --roles PVEVMAdmin,PVEDatastoreUser,PVEAuditor pveum acl modify /sdn/zones/localnetwork --users proxorchestrator@pve --roles PVESDNUser pveum user token add proxorchestrator@pve app --privsep 0
Copied!

The last command prints a table: copy the value row into Token Secret below. The token ID is proxorchestrator@pve!app. If the user already exists, the first line just reports it — that is fine. On Proxmox 7 the /sdn line can be skipped.
